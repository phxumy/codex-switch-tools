# Codex Switch Tools v1.2.0

中文 Windows 桌面配置工具。普通用户在本页 **Assets** 下载 `CodexSwitchTools.exe`，双击运行即可；不需要克隆源码、安装 Python、安装 PowerShell 7 或管理员权限。

## 本版改动

- Provider 模型下拉选择及“刷新模型列表”，新模型不必一直手工查名字。
- 每个 Provider 使用独立模型目录；官方 DeepSeek 与物理所不共享上下文和能力假设。
- 官方 DeepSeek V4 Pro、Flash 及实验视觉模型元数据；未知模型需确认，保守按文本处理，不根据名字猜图片能力。
- 记住各 Provider 的选择；恢复 OpenAI 时还原接管前的目录和上下文。
- 新增模型发现、目录隔离及恢复测试。

## 下载与升级

1. 下载本发行版的 `CodexSwitchTools.exe` 和 `SHA256SUMS.txt`，不要误下仅供开发者使用的 Source code ZIP。
2. 可在 PowerShell 执行 `Get-FileHash -Algorithm SHA256 .\CodexSwitchTools.exe`，与本页校验文件比较；不一致时不要运行。
3. 程序尚未签名，SmartScreen 可能提示未知发布者。确认来源是 `phxumy/codex-switch-tools`、版本和哈希后再自行决定是否信任；无需关闭系统防护。
4. 升级时先退出旧工具，用新 EXE 替换固定位置中的旧文件。用户配置和备份独立保存，不随 EXE 替换清空。

目标环境是 Windows 10/11 x64，依赖系统自带 Windows PowerShell 5.1 和 .NET Framework 4.x。自动测试使用 GitHub Windows runner；不能等同于验证了全部 Windows/企业安全策略组合。

## 切模型怎么用

选择 Provider → 刷新模型列表 → 选择模型 → 应用选择 → 完全退出并重启 Codex。刷新会向该 Provider 的 Base URL 发送模型列表请求及其 Key，请先确认端点可信。

Codex 部分版本仍可能显示“自定义 / Custom”。DeepSeek Provider 下不要选择 GPT / 5.6 等 OpenAI 模型；本工具不能拦截 Codex 原生界面之后的修改。未知模型不会自动获得视觉能力；物理所也不一定开放官方新模型。

工具管理的是请求配置，不能证明服务端最终调用的模型身份。完整教程见 [README](https://github.com/phxumy/codex-switch-tools/blob/v1.2.0/README.md)。
